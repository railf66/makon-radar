# OLX Ташкент — бот для риэлторского агентства (пилот)

Telegram-бот на русском и узбекском. Следит за новыми объявлениями о недвижимости в Ташкенте на OLX.uz
(продажа и аренда) и сразу присылает агентам те, что подходят под их фильтры.

## Что умеет
- Фильтры: продажа/аренда, квартира/дом/коммерция, комнаты, цена в $, районы Ташкента, «только собственники».
- Мгновенные уведомления: фото, цена, площадь, этаж, район, кнопка «Открыть на OLX».
- Отметка «Собственник» или «Посредник/агентство».
- Последние объявления по кнопке и выгрузка за 7 дней в Excel.
- Пилот: код доступа (`ACCESS_CODE`) и дата окончания (`PILOT_UNTIL`). Админ видит `/stats`.

## Установка на сервер (Ubuntu 22.04/24.04)
В консоли сервера под root:
```bash
apt-get update -y && apt-get install -y git
git clone https://github.com/railf66/makon-radar /root/makon-radar
cd /root/makon-radar && sh deploy/install.sh
```
Скрипт спросит токен бота и Telegram id админов, поставит бота как службу и включит автозапуск.
Код доступа с визитки: `sh deploy/pilot.sh makon2026 2026-11-15`.

### Агентства и тарифы
Подписка и пробный период общие на агентство, а не на каждого сотрудника.
- Новый человек вводит код с визитки → админу приходит заявка с кнопками «Одобрить» / «Отказать»
  (`TRIAL_APPROVAL=1`). После одобрения создаётся агентство с пробным периодом `TRIAL_DAYS` (14) дней,
  и бот выдаёт личный код агентства из 6 цифр.
- Коллеги вводят код агентства и попадают в него с тем же сроком и тарифом, пока есть свободные места.
  Если мест нет, бот отказывает и пишет админу, как добавить место.
- Тарифы: пробный (`TRIAL_SEATS`, 0 = без ограничения), Light (`LIGHT_SEATS`, 2 сотрудника), Pro (`PRO_SEATS`, 10 сотрудников).
  Сверх тарифа — платные места.
- За день до конца бот предупреждает всех сотрудников агентства и админа, после конца перестаёт слать объявления.
- Сотрудник видит своё агентство и код для коллег: «👥 Моя команда» (`/team`).

Команды админа в Telegram:
- `/users` — агентства, их сотрудники, тарифы, сроки и коды.
- `/extend №А 30`, `/extend №А 2026-12-31`, `/extend №А 0` (без срока).
- `/plan №А light`, `/plan №А pro`, `/plan №А light 1` (Light + 1 доп. место).
- `/move ID №А` — перенести сотрудника в агентство (так объединяют пилотных пользователей).
- `/rename №А Название`, `/newagency Название`, `/remove ID` — отключить сотрудника.

При обновлении каждый уже подключённый агент получает своё агентство с прежним сроком, потом их объединяют через `/move`.
Обновить код: `cd /root/makon-radar && git pull && sh deploy/install.sh` (настройки и база сохраняются).

## Запуск на своём компьютере
```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN от @BotFather и остальное
python -m bot.check_olx   # проверка сбора с OLX
python main.py
```

## Статус (2026-10-27)
- Сбор с olx.uz проверен вживую: квартиры и дома, продажа и долгосрочная аренда, Ташкент
  (category_id 13, 1147, 18, 330; region_id 5, city_id 4). Коммерция выключена.
- Проверка раз в 10 минут. Рассылаются только объявления, созданные за последние `FRESH_HOURS` часов
  (OLX поднимает старые объявления наверх).
- При 3 неудачных проверках подряд бот пишет админам (`ADMIN_IDS`), сам продолжает пробовать
  всё реже (до раза в час) и сообщает, когда сбор восстановился.
- Риск: OLX блокирует программы; бот представляется браузером. Возможен бан IP сервера.
  Решение принято владельцем пилота.
- `OLX_ENABLED=0` выключает сбор; `python -m bot.demo` шлёт 3 тестовых объявления.
- Дальше: деплой на VPS (systemd с автоперезапуском), после согласия на покупку сервера.

## Связь с секретарём Дильнозой

Если в `.env` указан `DILNOZA_WEBHOOK` (ссылка на вебхук Make), под каждым объявлением есть кнопка
«⭐ Дильнозе» (видят только админы или те, кто указан в `DILNOZA_USERS`). Она отправляет объект в Make, а Дильноза отвечает клиентам по этим объектам.
Раз в сутки Radar проверяет эти объекты на OLX и снятые убирает из таблицы Дильнозы
(`DILNOZA_CHECK_HOURS`). Без ссылки бот работает как раньше. Настройка Make: `docs/dilnoza-make.md`.

## Файлы
- `main.py` — запуск бота и фонового сбора.
- `bot/olx.py` — сбор и разбор объявлений OLX.
- `bot/handlers.py` — меню и фильтры.
- `bot/scheduler.py` — проверка OLX каждые `POLL_INTERVAL` секунд и рассылка.
- `bot/demo.py` — тестовая рассылка без OLX.
- `bot/i18n.py` — тексты RU/UZ и районы Ташкента.
- `bot/export.py` — Excel.
