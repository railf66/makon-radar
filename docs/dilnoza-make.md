# Radar → секретарь Дильноза (Make)

Агент видит объявление в Radar и нажимает «⭐ Дильнозе». Radar отправляет объект в Make,
Make записывает его в Google Таблицу, а Дильноза отвечает клиентам только по объектам из этой таблицы.

## 1. Таблица

Google Таблица «Объекты агентства», в первой строке столбцы:

`Дата | Агент | Сделка | Тип | Заголовок | Цена | Цена $ | Комнаты | Площадь | Этаж | Район | Адрес | Кто | Ссылка | ID`

Снятые с OLX объекты Radar убирает сам (см. п.2). Можно удалить строку и вручную.

## 2. Сценарий «Radar → таблица» (новый)

Radar шлёт в один вебхук два вида запросов: `action=add` (агент нажал кнопку) и
`action=remove` (раз в сутки Radar проверяет объекты на OLX, и если объявление снято,
просит удалить строку; админу приходит сообщение в Telegram).

1. Модуль **Webhooks → Custom webhook**, «Add», имя `Makon Radar`. Скопируйте ссылку.
2. На сервере: `sh deploy/set.sh DILNOZA_WEBHOOK ссылка` (из папки makon-radar).
   Кнопку видят только админы. Добавить других: `sh deploy/set.sh DILNOZA_USERS id1,id2`
3. В Radar нажмите «⭐ Дильнозе» под любым объявлением, Make сам узнает поля.
4. После вебхука поставьте **Router** с двумя ветками.
5. Ветка 1, фильтр `action` = `add`: модуль **Google Sheets → Add a row**, таблица из п.1, поля:
   Дата=`added_at`, Агент=`added_by`, Сделка=`deal`, Тип=`type`, Заголовок=`title`, Цена=`price`,
   Цена $=`price_usd`, Комнаты=`rooms`, Площадь=`area`, Этаж=`floor`, Район=`district`,
   Адрес=`address`, Кто=`owner`, Ссылка=`url`, ID=`id`.
6. Ветка 2, фильтр `action` = `remove`: **Google Sheets → Search rows** (столбец ID равен `id`),
   затем **Google Sheets → Delete a row** с `Row number` из поиска.
7. Включите сценарий (ON, Immediately).

Если удалить строку вручную, ничего не сломается: Radar просто не найдёт её при проверке.

Что приходит в вебхук (пример):

```json
{"action": "add", "id": "123", "added_at": "2026-11-01 14:24", "added_by": "Rail", "deal": "Продажа",
 "type": "Квартира", "title": "2-комн, Юнусабад", "price": "60 000 у.е.", "price_usd": 60000,
 "rooms": 2, "area": 54, "floor": "3/9", "district": "Юнусабадский район",
 "address": "Юнусабадский район", "owner": "собственник", "url": "https://www.olx.uz/...", "photo": ""}
```

## 3. Сценарий Дильнозы (существующий)

Перед модулем Claude:

1. **Google Sheets → Search rows**, таблица из п.1, без фильтра, Limit 50.
2. **Tools → Text aggregator**, источник — Search rows, текст:
   `{{Сделка}}, {{Тип}}, {{Комнаты}} комн., {{Площадь}} м², этаж {{Этаж}}, {{Район}}, {{Цена}}`
3. В системный промпт Claude добавьте:

```
Объекты агентства (предлагай только их):
{{текст из Text aggregator}}

Если подходящего объекта нет, скажи, что агент подберёт вариант, и попроси номер телефона.
Ссылки OLX и контакты владельцев клиенту не давай, приглашай на просмотр через агентство.
```
